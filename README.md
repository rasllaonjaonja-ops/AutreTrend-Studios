# AutreTrend Studios

**The next generation of AI content.**

Studio éditorial indépendant en français pour la veille manga/anime, la vérification des sources et la préparation de prépublications.

## Prototype 0.1
- Tableau de bord responsive, adapté au mobile.
- Radar avec exemples de démonstration clairement identifiés (pas de collecte réelle à ce stade).
- Prépublications sauvegardées localement dans le navigateur.
- Statut de vérification déclaré par l'utilisateur.
- Aucune publication automatique.

## Lancer
Ouvrir `index.html` dans un navigateur. Déploiement Cloudflare Pages possible en sélectionnant la racine du dépôt comme dossier de sortie, sans commande de build.

## Étapes suivantes
1. Connecter des flux RSS/Atom et des sources officielles.
2. Ajouter un classement de tendances explicable.
3. Intégrer l'assistant de rédaction et la vérification des faits.
4. Ajouter les visuels originaux et le montage vidéo côté navigateur.
5. Ajouter une base distante et des tâches planifiées selon les quotas gratuits disponibles.

Les API sociales et les services IA peuvent avoir des quotas, restrictions et coûts. La publication reste manuelle après validation humaine. Ce dépôt est indépendant de l'ancien projet Manga_studio.
